# Install AWS Load balancer controller 

### Step 1: Install `cert-manager`

The AWS Load Balancer Controller relies on webhooks and SSL/TLS certificates generated by `cert-manager`.

```bash
kubectl apply --validate=false -f https://github.com/cert-manager/cert-manager/releases/download/v1.13.1/cert-manager.yaml

```

Verify that all `cert-manager` pods reach `Running` status before proceeding:

```bash
kubectl get pods -n cert-manager

```

---

### Step 2: Download the Official Controller Manifest

Download the standard v2.6.0 release manifest:

```bash
curl -Lo v2_6_0_full.yaml https://github.com/kubernetes-sigs/aws-load-balancer-controller/releases/download/v2.6.0/v2_6_0_full.yaml

```

---

### Step 3: Update the Manifest Configuration

Open `v2_6_0_full.yaml` in an editor and update two mandatory sections for your self-managed setup:

#### 1. Configure Controller Deployment Arguments

Locate the `Deployment` spec for `aws-load-balancer-controller` and set your cluster name, VPC ID, and AWS Region:

```yaml
apiVersion: apps/v1
kind: Deployment
metadata:
  name: aws-load-balancer-controller
  namespace: kube-system
spec:
  template:
    spec:
      containers:
      - name: controller
        args:
        - --cluster-name=kubernetes    # Replace with your cluster name
        - --aws-vpc-id=vpc-011d404b571f3a74f   # Replace with your AWS VPC ID
        - --aws-region=us-east-1               # Replace with your AWS Region

```

```
# command to get current cluster name - bydefault cluster name is - kubernetes
kubectl config view -o jsonpath='{.contexts[?(@.name=="'$(kubectl config current-context)'")].context.cluster}'

```


#### 2. crete policy >> attach to role and attache role to ec2 instance 

```
curl -o iam_policy.json https://raw.githubusercontent.com/kubernetes-sigs/aws-load-balancer-controller/main/docs/install/iam_policy.json
aws iam create-policy --policy-name AWSLoadBalancerControllerIAMPolicy --policy-document file://iam_policy.json
```

attach role 
- go to instance see if any role attached if yes then >> attach this created policy to it
  

---

### Step 4: Apply the Manifests

Apply the updated YAML file directly to your cluster:

```bash
kubectl apply -f v2_6_0_full.yaml

```

---

### Step 5: Verify Deployment

1. Confirm the Deployment and Pods are running in `kube-system`:
```bash
kubectl get deployment -n kube-system aws-load-balancer-controller
kubectl get pods -n kube-system -l app.kubernetes.io/name=aws-load-balancer-controller

```


2. Inspect the logs to verify successful reconciliation without errors:
```bash
kubectl logs -n kube-system deployment/aws-load-balancer-controller -f

```
